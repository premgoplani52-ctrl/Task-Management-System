
# Task Management System

A desktop-based Task Management System developed
using Java Swing and MySQL.

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA

## Features
- User Login
- Task Assignment
- View Tasks
- Edit Tasks
- Delete Tasks
- Change Password
- Forgot Password

## Project Structure
- project1.java - Login Page
- Dashboard.java - Main Dashboard
- AssignTask.java - Assign New Tasks
- ViewTask.java - View and Manage Tasks
- ChangePassword.java - Change Password
- ForgotPassword.java - Password Recovery
- DBConnection.java - MySQL Connectivity

## Database
Database Name: task_management

## How to Run
1. Clone this repository.
2. Install Java JDK and MySQL.
3. Create the task_management database.
4. Execute the provided SQL script.
5. Configure your database connection.
6. Open the project in IntelliJ IDEA.
7. Run project1.java.
